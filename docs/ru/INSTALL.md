## 1. Что понадобится

| Что | Зачем |
| --- | --- |
| Компьютер или VPS, включённый 24/7 | На нём работает бот |
| [Docker](https://docs.docker.com/engine/install/) с Compose v2. На macOS — [OrbStack](https://orbstack.dev) или Docker Desktop | Запуск бота в контейнере |
| Git и Make | Скачать проект и управлять им |
| 5+ ГБ свободного места | Временные файлы, до 2 ГБ на каждую загрузку; удаляются сразу после отправки |
| Аккаунт Telegram | Создать бота и получить ключи |

Подойдёт любая архитектура: x86_64 или ARM, в том числе Apple Silicon (Mac mini M1–M4).

## 2. Ключи Telegram

Нужно получить четыре значения:

1. **`BOT_TOKEN`** — токен бота.
   Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя и username. BotFather пришлёт токен вида `123456789:AA...`.
2. **`APP_ID`** и **`APP_HASH`** — ключи Telegram API. Через них бот отправляет файлы до 2 ГБ, а не до 50 МБ.
   Войдите на [my.telegram.org](https://my.telegram.org) → **API development tools** → создайте приложение (название любое).
3. **`OWNER`** — ваш Telegram ID, число.
   Его можно узнать у [@userinfobot](https://t.me/userinfobot).

> [!WARNING]
> Никому не показывайте `BOT_TOKEN` и `APP_HASH` и не публикуйте файл `.env`: он уже добавлен в `.gitignore`.

## 3. Установка

```sh
git clone https://github.com/yinon-mitin/iris.git
cd iris
make init
```

`make init` создаёт `.env` из шаблона, папку `data/` для базы и пустой файл `youtube-cookies.txt`. Откройте `.env` в любом редакторе и заполните первый блок:

```ini
APP_ID=12345678
APP_HASH=0123456789abcdef0123456789abcdef
BOT_TOKEN=123456789:AA...
OWNER=111111111
AUTHORIZED_USER=
```

Проверьте и запустите:

```sh
make test
make up
make logs
```

Первая сборка займёт несколько минут. В журнале должны появиться строки `Firewall: home network and private addresses blocked`, `yt-dlp version: …` и `Session started`. Откройте своего бота в Telegram, нажмите **Start** и отправьте ссылку.

> [!NOTE]
> Контейнеру нужно право `NET_ADMIN`, чтобы при запуске закрыть доступ к вашей домашней сети. Оно уже указано в `docker-compose.yml`; сам бот работает без него. Подробнее — в [Архитектуре](ARCHITECTURE.md#фильтр-исходящих-соединений).

## 4. Доступ для друзей и родных

Бот приватный: по умолчанию им может пользоваться только владелец (`OWNER`). Пользователей можно добавлять прямо из бота, перезапуск не нужен. Эти команды видит и может выполнять только владелец:

| Команда | Что делает |
| --- | --- |
| `/invite` | Одноразовая ссылка-приглашение. Отправьте её человеку: он нажмёт **Start** и сразу получит доступ, а вам придёт уведомление |
| `/adduser 222222222` | Дать доступ по Telegram ID. Бот показывает ID незнакомцу, когда тот нажимает **Start**. Ещё можно ответить командой `/adduser` на пересланное от человека сообщение |
| `/deluser 222222222` | Убрать доступ |
| `/users` | Список всех, у кого есть доступ |
| `/notify` | Включить или выключить уведомления о новых людях |

Когда незнакомый человек нажимает **Start**, бот присылает вам уведомление с кнопками «✅ Разрешить» и «🚫 Отклонить». Об одном и том же человеке бот пишет не чаще раза в час.

Пользователи, добавленные через бота, хранятся в базе (`data/`) и сохраняются после перезапуска. Можно и вписать ID в `.env` (несколько номеров через запятую, без пробелов), а затем выполнить `make up`:

```ini
AUTHORIZED_USER=222222222,333333333
```

Таких пользователей убрать командой `/deluser` нельзя, только через `.env`.

## 5. Оформление бота

Всё делается через [@BotFather](https://t.me/BotFather):

| Команда | Что задать |
| --- | --- |
| `/setuserpic` | Аватарку: [`assets/logo.png`](../../assets/logo.png) |
| `/setdescription` | Текст, который виден до нажатия Start. Например: «Пришлите ссылку — я скачаю видео, фото или файл и отправлю сюда.» |
| `/setabouttext` | Короткое описание в профиле бота |
| `/setjoingroups` → **Disable** | Запретить добавлять бота в группы |

Меню команд («/») бот настраивает сам при запуске.

## 6. Все настройки `.env`

| Переменная | По умолчанию | Описание |
| --- | --- | --- |
| `APP_ID`, `APP_HASH` | — | Ключи Telegram API с my.telegram.org. **Обязательно** |
| `BOT_TOKEN` | — | Токен от @BotFather. **Обязательно** |
| `OWNER` | — | Telegram ID владельца, можно несколько через запятую. **Обязательно** |
| `AUTHORIZED_USER` | пусто | ID пользователей через запятую. Владелец имеет доступ всегда |
| `WORKERS` | `16` | Сколько сообщений бот обрабатывает одновременно |
| `DB_DSN` | `sqlite:////data/iris.db` | База пользователей и настроек, хранится в папке `./data` |
| `REDIS_HOST` | пусто | Пусто — кэш в памяти. Можно указать внешний Redis |
| `YTDLP_UPDATE_INTERVAL` | `86400` | Как часто проверять обновления yt-dlp, в секундах |
| `ENABLE_ARIA2` | `False` | Использовать aria2 для команды `/direct` |
| `M3U8_SUPPORT` | `False` | Разрешить прямые ссылки на `.m3u8` |
| `AUDIO_FORMAT` | пусто (m4a) | Формат для режима «Только звук», например `mp3` |
| `TMPFILE_PATH` | пусто | Папка для временных файлов внутри контейнера |
| `ENABLE_VIP`, `PROVIDER_TOKEN` | `False` | Платный режим из оригинального проекта. Для приватного бота не нужен |

**Cookies для YouTube.** Если YouTube требует войти в аккаунт (часто бывает на VPS), экспортируйте cookies из браузера в формате Netscape в файл `youtube-cookies.txt` в корне проекта и выполните `make restart`. Используйте отдельный аккаунт, а не основной: всё, что видит этот аккаунт, смогут скачать все пользователи бота. Файл исключён из Git.

## 7. Где запускать: дом или VPS

| | Домашний компьютер (например, Mac mini) | VPS в дата-центре |
| --- | --- | --- |
| Цена | Бесплатно | От ~5 $/мес |
| Доступность | Пока включён компьютер и есть интернет | 24/7 |
| Блокировки сайтов | Домашний IP блокируют реже | YouTube часто просит cookies, VK может ограничивать зарубежные IP |
| Скорость отправки | Зависит от домашнего интернета | Обычно высокая |

VK Video и OK.ru могут ограничивать доступ для IP вне России. Если на вашем сервере видео не открываются, используйте прокси с подходящим IP.

На macOS отключите сон: **Системные настройки → Экономия энергии**. Ещё включите автозапуск OrbStack или Docker Desktop при входе в систему. Контейнер перезапускается сам (`restart: unless-stopped`).
