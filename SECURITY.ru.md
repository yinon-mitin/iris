# Политика безопасности

[English](SECURITY.md) · [Русский](SECURITY.ru.md)

## Как сообщить об уязвимости

Сообщайте об уязвимостях приватно, через [GitHub security advisories](https://github.com/yinon-mitin/iris/security/advisories/new), а не в публичном issue. Не прикладывайте токены бота, ключи API, адреса серверов, журналы с ID пользователей и скриншоты личных чатов.

## От чего защищает Iris

| Угроза | Защита |
| --- | --- |
| Посторонние пользуются вашим ботом | Проверка доступа на каждой команде, сообщении и кнопке; список, одобренный владельцем |
| Ссылка ведёт в вашу домашнюю сеть, Tailscale или на хост Docker (SSRF) | Фильтр исходящих соединений контейнера: без него бот не запускается, процесс бота снять его не может; понятный отказ в чате |
| Загрузки копятся на диске | Своя временная папка у каждой задачи, удаляется по её окончании; уборка раз в час после сбоев |
| Ошибка Telegram обрывает загрузку | Обновление прогресса отделено от загрузки; отправка повторяется |
| Секреты попадают в Git | `.env`, `data/`, cookies и сессии исключены; `make check` ищет токены и ключи |

Подробности устройства: [Архитектура](docs/ru/ARCHITECTURE.md).

## Что остаётся на владельце

- Храните `.env` и резервные копии в тайне: токен бота и `APP_HASH` дают полный контроль над ботом.
- Оставляйте доступ по приглашениям. Дневных лимитов нет, и все загрузки идут с вашего IP-адреса.
- Если добавляете cookies YouTube, используйте отдельный аккаунт: всё, что видит этот аккаунт, смогут скачать все допущенные пользователи.
- Не убирайте `cap_add: [NET_ADMIN]` из Compose: без него контейнер не запустится, а не будет работать без фильтра.
- Если секрет когда-либо попал в коммит, удалить файл недостаточно: отзовите его (`/revoke` у BotFather, новый `APP_HASH`) и перепишите историю, прежде чем делиться репозиторием.

## Поддерживаемые версии

Поддерживается только последняя версия `main`. yt-dlp бот обновляет сам; Iris обновляется командой `make update`.
